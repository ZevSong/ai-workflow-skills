# 全自动：缺少调度能力

材料类型：手工编写的输入与预期输出；没有实际调用或模拟成功创建 Desktop 会话。

## 输入条件

用户已经发送全自动 Main 启动提示词，要求按总卡创建独立 Desktop Worker/Reviewer 会话。当前宿主仅提供文件读取和内部子 Agent 工具，没有独立 Desktop 会话的创建、续接或状态查询能力。

## 预期输出片段

> 业务调度状态：BLOCKED。
>
> 已核对任务卡和材料；当前环境没有所需的独立 Desktop 会话调度工具。内部子 Agent 属于不同执行载体，尚未获得改用该载体的决定。
>
> 可以选择由用户按已交付的具名提示词逐个启动会话，或在接受内部子 Agent 载体并满足隔离条件后调整计划。现有任务卡和提示词保留，当前没有启动替代会话。

实际回复应同时给出下一具体会话的已实例化提示词，包含名称、角色、仓库、卡片相对路径、范围及停止点，不能只给抽象建议。本页仅演示能力缺口处理；完整输出形式见人工任务包案例。

## 验收要点

- 说明缺少的实际能力，而非泛泛称“无法执行”。
- 没有把内部子 Agent 当成独立 Desktop 会话，未获得选择前不静默降级。
- 没有反复尝试同一不可用工具或创建重复会话。
- 未执行的业务测试、审查、集成和发布如实标为未运行。
- 用户后续接受可用载体后，更新执行计划并继续已授权范围，不重新询问已经决定的需求。
