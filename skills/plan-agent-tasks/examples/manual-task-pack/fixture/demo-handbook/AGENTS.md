# demo-handbook 项目规范

- 这是用于任务包生成测试的虚构中文文档仓库，目录内容可公开。
- 若用户无明确要求，禁止检查SHA。
- 仅修改当前任务卡授权的文件；保留已有文件和用户改动。
- 文档验收采用可复查的阅读步骤，不虚构已有脚本、测试命令或运行结果。
- 项目没有额外人类审查门禁；人工模式中的用户启动动作不是技术审查通过。
- 默认不推送、不创建远端资源、不合并、不发布。本次只生成任务包，不实施文档成果或启动其他会话。
- 任务包位置为仓库根相对目录 `docs/task-packets/DEMO-DOCS/`。本目录是普通文件 fixture，未初始化 Git；外层仓库的分支和改动不代表本项目状态。
