# DEMO-DOCS · Main · 使用文档统筹与集成核对

## 身份与入口

- Parent：`DEMO-DOCS`；卡片仓库：`demo-handbook`；根相对路径：`docs/task-packets/DEMO-DOCS/main.md`。
- 总卡：[packet.md](packet.md)；需求：[README.md](../../../README.md)；规范：[AGENTS.md](../../../AGENTS.md)；会话入口：[prompts.md](prompts.md)。以上文件已随本地草案提供。
- 人工模式来自用户明确选择。负责材料、依赖、状态、交接和集成核对；不写两份业务文档。
- 本次生成没有启动本会话。用户将来明确启动后，允许读材料、维护本卡约定的状态和核对报告；默认不推送、不创建远端资源、不合并、不发布。项目没有额外人类技术审查门禁。禁止检查 SHA，也不改用其他哈希。

## 人工调度与状态

不得自动创建、委派、发送执行消息或续接其他会话。每次只给用户下一步、具体会话名称、启动条件及对应完整提示词，然后等待用户触发。用户自行启动的 Worker/Reviewer 可完成整张卡片，无需逐段询问。

执行载体为用户手动建立的独立会话；检查文件读取、隔离工作区和用户能否手动打开会话即可。无需自动调度工具，不把内部子 Agent 当作独立会话。若用户未来改选自动模式，先核实相应创建、续接、状态与隔离能力并更新计划，当前不能静默换模式或安装工具。

未来唯一活动状态：仓库 `demo-handbook` 根相对路径 `docs/task-packets/DEMO-DOCS/reports/status.md`（计划创建），Main 单独维护。登记计划名称、真实会话标识或可复查会话入口、Task、阶段、状态、交付批次和证据入口；未有真实标识就写未创建，不编造 ID。不得把同一角色的修复或复审登记为新逻辑会话。

## 初始化与恢复

1. 从总卡、项目输入和已有报告恢复；如果报告尚未创建，明确记录未执行。输入缺失就报告具体卡片仓库和相对路径，不用聊天替代。
2. 本 fixture 未初始化 Git。将来由用户在实际目标仓库准备可供隔离工作的基线；Main 只检查分支名称、工作区状态和可读材料，不读取禁止的证据。隔离未就绪时记录执行受阻及所缺材料，不写业务文件。
3. 核对用户提供的真实会话入口与现有动作，已有 Main、修复 Worker 和复审 Reviewer 优先续接；会话状态不确定时先核对，不能重复启动。会话丢失时用卡片、交付对象和报告恢复，独立 Reviewer 不继承作者聊天。
4. 人工模式恢复后仍只提供提示词。没有对应用户启动动作，不触发下一会话。无未满足依赖的另一任务可以提供就绪提示词，交由用户决定何时启动。

## 并行、交接与审查

- 同批次最多两个 Worker，分别使用 `docs/demo-docs-01`、`docs/demo-docs-02` 独立分支及独立 worktree。目标文档、交接报告各自独占；Main 不占用 Worker 工作区。
- 仅在接收方可读 README、AGENTS、相关卡片、目标交付文件与该批次报告后给出 Reviewer 入口。采用用户允许的文件交付方式；不得把本例同机可读作为跨机器已验证。
- 独立 Reviewer 使用全新会话与隔离审查工作区，报告绑定 Worker 本次批次及完整交付内容。新修复产生新批次，旧审查不能自动覆盖。发现问题只给原 Worker 修复提示词，修复后给原 Reviewer 复审提示词；每一步均等用户续接。
- 同一阻塞重复且无新证据或可行方案时停止重复操作，报告缺少什么、影响什么和可行下一步；范围或验收变化需先回到需求核对。不要无限新建会话。

## 集成核对与停止

只有 DEMO-DOCS-01 和 DEMO-DOCS-02 均有本次交付、独立阅读验收和所有问题关闭证据，且用户续接 Main，才进入集成核对。

只读并排阅读两份交付文档，对照总卡 R1–R3 及 Worker 的 A1–A5、B1：术语一致、生成与执行的界限一致、没有越界安装或调度承诺。记录逐项观察及文件相对位置。若需语义改动，交回对应 Worker，再要求该任务独立复审。这里的“集成”是成果一致性核对，不包含 Git 合并。

唯一集成结果报告：`demo-handbook` 根相对路径 `docs/task-packets/DEMO-DOCS/reports/integration.md`（计划创建）。列出交付批次、两份文档、两个审查报告、逐项阅读结果、未解决问题和下一步。分别报告本地阅读、业务审查、提交、跨机器、合并与发布的真实状态；不推导未运行结果。完成报告后停止，清理工作区、归档会话和分支删除均不在本包授权内。
