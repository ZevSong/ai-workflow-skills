# DEMO-DOCS-01 · Reviewer · 快速入门独立审查

## 身份、对象与输入

- Parent：`DEMO-DOCS`；Task：`DEMO-DOCS-01`；模式：`manual`。用户首次新建独立会话，复审续接本会话；不继承作者工作聊天。
- 审查仓库与卡片仓库：`demo-handbook`；本卡根相对路径：`docs/task-packets/DEMO-DOCS/reviews/DEMO-DOCS-01.md`。
- 审查目录为独立审查 worktree 的仓库根 `.`。输入：[README 原始请求](../../../../README.md)、[AGENTS.md](../../../../AGENTS.md)、[总卡](../packet.md)、[Worker 卡](../workers/DEMO-DOCS-01.md)。
- 待审对象：`demo-handbook` 的 `docs/quickstart.md`（计划创建），以本任务 `docs/task-packets/DEMO-DOCS/reports/DEMO-DOCS-01-handoff.md`（计划创建）中的交付批次、分支名及完整内容副本绑定。
- 启动条件：用户已提供当前交付文件、交接报告、全部输入及隔离审查区，并发送本提示词。逐行比较文件与该批次内容副本，不以作者 PASS 代替验证；对象不符或材料缺失就报告受阻。

## 权限与独立验证

只读需求、成果、实际差异和证据。唯一允许写入为 `demo-handbook` 根相对路径 `docs/task-packets/DEMO-DOCS/reports/DEMO-DOCS-01-review.md`（计划创建）。不修复文档、不替 Worker 提交、不推送、不创建远端资源、不合并、不发布、不自行唤起其他会话。禁止检查 SHA，不使用其他哈希替代。无需自动调度工具。

在隔离审查区用文本阅读器独立执行 Worker 卡 A1、A2、B1：逐段确认四步及顺序、完整目录含资源、按宿主说明安装、显式调用与查看结果；定位“生成计划不会启动业务”的边界句；全文核对没有越界安装或调度承诺，并检查文件差异未越界。逐项记录输入文件和交付批次、实际阅读操作、行号或标题、观察与 PASS/FAIL；没有可用的既有测试命令。当前生成阶段这些业务验证均为 UNRUN。

## 结论、问题和复审

通过条件：A1、A2、B1 都有独立证据且符合要求，所有已提出问题已关闭。缺失证据写 UNRUN，阻碍审查的缺失材料写 BLOCKED，违反要求写 FAIL，不把作者结论照抄为 PASS。项目无额外人类技术审查门禁；用户继续人工流程不替代本审查结论。

每个问题记录稳定编号、文件相对位置、影响、阅读复现步骤、预期/实际、修复要求和复核方式。报告包含本次交付批次、检查结果、问题及状态、给 Main 的结论。报告后停止，由用户将问题交原 Worker；不自行发送触发执行的消息。

修复后用户续接本会话，先确认新批次与完整交付内容，复核原问题并重读受影响的 A1/A2/B1；更新同一报告，保留原问题和复核证据。修改后的内容必须重新得到审查结论。若需替换会话，携带本卡、明确交付对象、原报告和问题恢复，仍不继承作者聊天。
