# plan-agent-tasks

把已经讨论清楚的需求转为可执行、可验收的多 Agent 任务包。适合使用 Main / Worker / Reviewer 分工、需要明确交接材料和会话顺序的开发工作。

## 输入与输出

输入是已确认的需求、目标仓库、可观察验收条件和必要约束。若需求决定尚不明确，Skill 先列出缺口、影响和需要用户决定的内容；可从代码和文档查明的事实由 Agent 自行读取。

输出包含：

- 总任务卡、Main 卡、每个 Worker 及其独立 Reviewer 的任务卡。
- 具体会话名册，例如 `DOCS-01 · Worker · 快速开始文档编写`。
- Mermaid 流程图，展示依赖、并行关系、修复/复审和阶段门禁。
- 每个会话单独可复制的启动、恢复及适用续接提示词，同时写入文件和最终回复。

任务卡与提示词中的本地文件引用采用相对路径。跨仓材料使用仓库标识和仓库内路径，不能假设另一台机器的仓库也放在相邻目录。

## 安装与调用

将本 Skill 的整个目录安装到宿主支持的位置，保留 `references/`、`assets/`、`agents/`、示例和 [许可证](LICENSE)，不要只复制 `SKILL.md`。

已有同名安装时，先保存本地定制，再按宿主支持的方式更新；不要同时加载两份同名 Skill。

Codex 可通过内置安装器获取：

```text
使用 $skill-installer，从 GitHub 仓库 ZevSong/ai-workflow-skills 安装 skills/plan-agent-tasks，保留完整目录及 MIT 许可证。
```

安装后先讨论需求，再发送：

```text
使用 $plan-agent-tasks，根据已确认需求，按人工模式生成任务包。
```

```text
使用 $plan-agent-tasks，根据已确认需求，按全自动模式生成任务包。
```

```text
使用 $plan-agent-tasks，根据已确认需求，按半自动模式生成任务包，将任务组织为可验收的大阶段。
```

这三段是使用方式示例，每次选择一种。生成计划不会执行业务；用户检查任务包后，发送生成的 Main 启动提示词开始执行。没有指定模式时默认人工。

## 三种模式

| 模式 | 调度方式 | 人工参与 |
| --- | --- | --- |
| 人工 | 不自动创建或续接其他会话，由 Main 提供下一步提示词 | 用户逐个启动、返修和复审 |
| 全自动 | Main 按依赖调度开发、独立审查、修复、复审与已授权集成 | 启动 Main、处理真实阻塞和所需批准 |
| 半自动 | 获准阶段内自动推进；跨阶段设置确认门禁 | 启动首阶段，逐次确认后续阶段 |

任务较多时才主动建议半自动；用户直接指定时不受任务数限制。选择模式不改变范围、验收或项目权限。详细规则由 [Skill 入口](SKILL.md) 及其引用维护。

## 宿主与验证范围

| 环境 / 能力 | 当前说明 |
| --- | --- |
| Codex 加载与显式调用配置 | 提供 `agents/openai.yaml`，关闭隐式调用；元数据可静态校验 |
| 任务包生成 | 提供实际生成案例与检查方式，见 [示例](examples/README.md) |
| Desktop 独立会话自动调度 | 需要创建、续接、等待/状态查询和隔离能力；尚未端到端实测 |
| 内部子 Agent 执行 | 需要用户接受该载体，并保证工作区和 Reviewer 上下文隔离；不等同于独立 Desktop 会话 |
| 其他 Agent | 通用 Markdown 格式可供适配；触发策略和执行模式尚未逐个平台验证 |

显式调用是本 Skill 的执行约定。Codex 的 `allow_implicit_invocation: false` 为其宿主配置；其他产品需要对应配置或验证。参考 [Agent Skills 规范](https://agentskills.io/specification) 和 [Codex 官方文档](https://learn.chatgpt.com/docs/build-skills)。

所需调度工具不可用时，Main 报告缺口并提供人工入口，由用户决定切换；不静默替换执行载体。Skill 不提供常驻服务，不承诺应用关闭后继续执行。

## 示例与反馈

从 [示例索引](examples/README.md) 查看需求缺口、人工完整任务包、半自动阶段确认和自动模式能力缺失案例。具体证据和未验证范围见 [验证记录](examples/validation.md)。

反馈应包含最小需求输入、所用 Agent/模式、预期与实际输出，并移除敏感材料。功能变更优先附可复查案例。
